# Design defination

- BluetoothとGPS間でswitchできるようにしたい
    - すれ違い/グループ/partyでそれぞれ違うけど固定でGPSとかblなんじゃなくてある程度共通化されたinterfaceを元にGPS/BL用に拡張された感じ。
        - つまりはグループもBluetoothでできるような設計にしたい(優先度低
- 通常の地図を用いることで生まれる優位性はどこにもない
    - グループは大きさの異なる円であることが実態。それを地図に投影する必要性は有るのか？つまりその場にいて周りがわかるのにわざわざ地図を使う必要性はあるのか？それよりはグラフ表現の方が良さそう。
        - 大グループと小グループが大きさの異なるvertexになる。構造化ができる
