# CHAIN v2 デザイン 現状まとめ

最終更新: 2026-10-17 ／ Figma ファイル: `CHAIN`（Page 1）

## コンセプト

- 大きすぎず小さすぎない、気軽に入れる中くらいのSNS
- Bluetooth 圏内など「すぐ近くの人」と気軽につながる
- 地図ではなく、グループ＝大きさの違う円として **グラフで** まわりを表す
- DM なし（会話はパーティとグループの中だけ）

## デザインのルール

| 項目 | 内容 |
|---|---|
| フォント | Zen Maru Gothic（本文）／ Baloo Da（ロゴ・大きな数字）／ Material Symbols Rounded（アイコン） |
| 基本色 | 文字 `#3f3a3a` `#1c1c1c`、サブ `#9a9494`、薄い `#b0aaaa`、濃いボタン `#5b5555`、背景 `#f5f5f5` / `#ffffff` |
| グループ（オープン） | `#F2C4B8` |
| 招待制グループ | `#CF9AEA` |
| ユーザー | `#AAD3F6`（アイコン設定済みの人は縁だけこの色） |
| パーティ | `#5b5555` の波形 |
| オンライン表示 | `#6fcf97` |
| 投稿ボタン | 右下の丸い ＋ ボタン（押すと「グループを作る」「新しい投稿」が上に伸びる） |
| レイアウト | SNS 系はカードなしのフラット（区切り線）が基本。カード版は別デザインとして並置 |

## 下のタブバー

`ちかく` / `パーティ` / `友達` / `プロフィール` の4つ。
各タブはアイコン＋文字を `Tab / ○○` という名前のグループにまとめてある（12画面・48タブ）。

## 画面のつながり（想定）

- ちかく → ＋ → メニュー → 「新しい投稿」= Compose ／「グループを作る」= Create Group
- ちかく → グループの円 → Group → コメント → Group (Reply)
- プロフィール → メモリー ／ これまでの統計 ／ 設定

## まだ手を付けていないこと

- **プロトタイプのリンク**：画面どうしをつないでいない（今使っている Figma 連携にはリンクを作る機能がない）
- **コンポーネント化**：タブバーやボタンは各画面のコピー。文言を変えるときは画面ごとに直す必要がある
- **SVG 取り込み**：画面の中身は SVG から作っているので、オートレイアウトになっていない（文字は直接編集できる）
- **フラット化**：Party・Profile・Memory・Stats は角丸カードのデザインのまま
- **細かい点**
  - ちかくの「今日」の最後の行に ＋ ボタンが少し重なる
  - Menu Open のボタンの下から、後ろの「8回目」がわずかに見える
- **Welcome**：v1 のままで、v2 用には作り直していない
